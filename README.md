# 大邱 × 福岡 2026.5.16–18 私房三天兩夜

> 5 月 16 日（六）— 5 月 18 日（一），2 人同行，大邱進、福岡出。

線上版：<https://jack926509.github.io/daegu-fukuoka-trip/>

## 行程概覽

### Day 1 · 5/16（六）大邱舊城散步 → 飛往博多
清晨 05:25 落地大邱國際機場，先進城吃國一따로국밥韓牛骨湯飯暖胃，接著徒步走完近代文化胡同（藥令市博物館・桂山天主教堂・青羅之丘・韓服體驗），中午 11:30 前到巨松燉排骨喫갈비찜，下午到東城路逛街順買美成堂扁餃子，16:00 出發大邱機場，搭 18:25 班機飛福岡，落地後直奔博多吃 ShinShin 豚骨拉麵當宵夜。

### Day 2 · 5/17（日）門司港懷舊散步・牛腸鍋・中洲屋台
07:45 KITTE 速戰早餐，08:30 上 JR 直奔門司港懷舊地區，看 1914 年歐式紅磚車站、走 780 公尺關門海峽海底隧道穿越到山口縣，午餐吃門司港限定的燒咖哩。下午回博多逛 Canal City 看 20:00 光雕秀，晚餐預訂 Tabelog 4.4 的「もつ鍋一藤」吃牛腸鍋，飯後散步到中洲屋台街感受日本夜文化遺產，再回 KITTE B1F とり皮大臣配冰啤酒收尾。

### Day 3 · 5/18（一）太宰府天滿宮 · 回台灣
09:30 西鐵到太宰府，逛天滿宮參道、看隈研吾設計的竹製星巴克、到天滿宮後方的足湯咖啡廳泡腳。中午回博多吃華味鳥水炊鍋（KITTE 9F），下午衝天神地下街最後採買（大丸退稅約 15%、岩田屋限定獺祭、明太子、博多通りもん），14:30 一定要離開天神搭地鐵到福岡機場，16:20 班機飛回台北。

## 重點提醒
- **巨松燉排骨**：11:30 前到，下午常賣完。
- **もつ鍋一藤**：出發前一週 Tabelog 訂位。
- **ShinShin 天神本店週日公休**：5/17 改去 KITTE B1F とり皮大臣。
- **Day 3 最晚 14:30 離開天神**，國際線 90 分前要報到。
